# Обновление карты на сайте

## Когда нужна эта задача

При обновлении карты в Figma. Разработчик выгружает новый SVG карты из Figma, кладёт его в `img/day/map/map{number}.svg`, называет номер и просит перенести карту на сайт.

---

## Входные данные

- **Файл с новой картой:** `img/day/map/map{number}.svg` (например, `map42.svg`)
- **Целевой файл:** `source/index.html`, секция `map`

## Что нужно сделать

1. Открыть `img/day/map/map{number}.svg` и скопировать всё содержимое.
2. В `source/index.html` найти существующий код карты внутри секции `map` и **заменить его целиком** на скопированный SVG-код.
3. Применить к вставленному коду следующие преобразования (в указанном порядке):

### Шаг 1. Класс для `<svg>`

Добавить к корневому тегу `<svg>` (родительскому контейнеру вставленной карты) класс `map__scheme`.

**Пример:**
```html
<!-- Было: -->
<svg width="..." height="..." viewBox="...">
<!-- Стало: -->
<svg class="map__scheme" width="..." height="..." viewBox="...">
```

### Шаг 2. Классы для фигур

Найти все теги `<g>` у которых есть атрибут `id` вида `"figure {число}"` (например, `id="figure 27"`). Каждому такому тегу добавить класс `"figure figure_{число}"`.

**Правила:**
- id проверяется строго: содержит пробел между `figure` и числом.
- Число может быть любым (1, 27, 103 и т.д.).
- Если после числа идёт нижнее подчёркивание с дополнительным номером (например `id="figure 27_2"`, `id="figure 27_1"`), то для класса берётся только часть **до** нижнего подчёркивания. То есть для `figure 27_2` и `figure 27_1` класс в обоих случаях будет `figure figure_27`.
- Класс добавляется к существующим классам, если они есть. Если классов не было — добавляется как единственный класс.

**Пример:**
```html
<!-- Было: -->
<g id="figure 27">
<!-- Стало: -->
<g class="figure figure_27" id="figure 27">
```

**Пример с уже существующим классом:**
```html
<!-- Было: -->
<g class="some-class" id="figure 5">
<!-- Стало: -->
<g class="some-class figure figure_5" id="figure 5">
```

**Пример с составным номером через нижнее подчёркивание:**
```html
<!-- Было: -->
<g id="figure 27_2">
<!-- Стало: -->
<g class="figure figure_27" id="figure 27_2">

<!-- Было: -->
<g id="figure 27_1">
<!-- Стало: -->
<g class="figure figure_27" id="figure 27_1">
```

### Шаг 3. Класс `rect` для path-прямоугольников

Для каждого тега `<g>`, к которому на Шаге 2 был добавлен класс `figure figure_{число}`:

1. Проверить, есть ли внутри этого `<g>` дочерний тег `<rect>`.
   - Если `<rect>` **есть** — ничего не делать, пропустить этот `<g>`.
2. Если `<rect>` **нет**, найти внутри этого `<g>` тег `<path>`.
3. Если у такого `<path>` в атрибуте `id` встречается подстрока `"Rectangle"` (регистр не имеет значение), то добавить этому `<path>` класс `"rect"`.

**Важно:** Ищем `<rect>` и `<path>` только среди **прямых** детей элемента `<g>` (дочерние элементы первого уровня вложенности), а не внутри вложенных `<g>`.

**Пример:**
```html
<!-- Было: -->
<g class="figure figure_27" id="figure 27">
  <path id="Rectangle 42" d="M..."/>
</g>
<!-- Стало: -->
<g class="figure figure_27" id="figure 27">
  <path class="rect" id="Rectangle 42" d="M..."/>
</g>
```

**Пример, когда rect уже есть (ничего не делаем):**
```html
<g class="figure figure_27" id="figure 27">
  <rect x="..." y="..." width="..." height="..."/>
  <path id="Rectangle 42" d="M..."/>
</g>
```

---

## Что НЕ нужно делать

- Не трогать другие файлы.
- Не изменять сам SVG-код из файла `map{number}.svg` — только скопировать его целиком и применить классы по спеце выше.
- Не изменять существующие id элементы — только **добавлять** классы.
- Не трогать другие секции в `index.html`.
- Если у тега `<g>` нет id вида `figure {число}` — не добавлять ему класс `figure`.
- Если внутри `<g>` с классом `figure` нет path с "Rectangle" в id — не добавлять класс `rect`.

## Формат запроса

Разработчик говорит: *«Обнови карту, номер {number}»*

Где `{number}` — порядковый номер файла `map{number}.svg` в `img/day/map/`.
